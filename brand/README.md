# Identidad de NexoMark IA

**NexoMark IA** conecta las tres partes centrales del producto: las ideas del
marketero, las campañas creadas con inteligencia artificial y la aprobación del
cliente.

## Concepto del símbolo

- La **N** representa NexoMark y la conexión entre participantes.
- Los dos nodos de color muestran el inicio y el resultado del flujo creativo.
- Las ondas laterales representan voz, difusión y campañas publicitarias.
- La chispa superior identifica la generación mediante inteligencia artificial.

## Colores

| Uso | Color |
|---|---|
| Violeta principal | `#625BFF` |
| Violeta profundo | `#5546E8` |
| Cian de conexión | `#16B8D4` |
| Cian claro | `#BFF6FF` |
| Fondo oscuro | `#0D0E19` |

La tipografía recomendada es **Inter**, con peso 800 para el nombre y pesos
400–600 para textos de interfaz.

## Archivos

- `nexomark-mark.svg`: isotipo para favicon, aplicación e interfaces compactas.
- `nexomark-logo.svg`: logo horizontal principal.
- `nexomark-logo-preview.png`: vista previa raster para documentos y exposición.

No deformar el logo, cambiar sus proporciones ni separar la cápsula `IA` del
nombre. El isotipo puede utilizarse solo cuando el nombre ya sea visible en el
contexto.
